# Source verification and reuse notes

Checked November 8, 2026. These URLs are the live county sources, not copied datasets.

| Layer | Source | Geometry | Displayed fields | Live count at check |
| --- | --- | --- | --- | ---: |
| County parks | [MapServer/6](https://gis2.norfolkcounty.ca/arcgis/rest/services/Services_Public_GISviewer/Parks_Recreation/MapServer/6) | Polygon | Name, Address, Class | 97 |
| County woodlots | [MapServer/13](https://gis2.norfolkcounty.ca/arcgis/rest/services/Services_Public_GISviewer/Parks_Recreation/MapServer/13) | Polygon | NAME, ACREAGE, STATUS | 36 |
| Tree inventory | [MapServer/14](https://gis2.norfolkcounty.ca/arcgis/rest/services/Services_Public_GISviewer/Parks_Recreation/MapServer/14) | Point | SPECIES, VIGOUR, DBH_1, DATE_INSPECTED | 41,416 |

All three layers answered metadata and count queries, advertise `Query`, and returned `Access-Control-Allow-Origin: https://arcgisdemo.apiariavera.com` when requested with that origin. Recheck with `npm run data:check` after deployment. CORS is service behavior, so it can change. The tree service has more fields than this portfolio needs, including work-related notes; the app requests and displays only the four fields listed above. It makes no editing calls.

The app does not yet draw a municipal boundary. Norfolk and Haldimand are separate municipalities; the legal dividing line is described in [Ontario Regulation 94/00, section 2](https://www.ontario.ca/laws/regulation/000094). For a future outline, Ontario's [Municipal Boundary - Lower and Single Tier](https://geohub.lio.gov.on.ca/datasets/municipal-boundary-lower-and-single-tier/explore) is a more suitable source than Norfolk's open-data item named “County Boundary”: the latter's [full description](https://opendata.norfolkcounty.ca/datasets/Norfolk::county-boundary/about) says it represents a clipped portion of Lake Erie.

The [service directory](https://gis2.norfolkcounty.ca/arcgis/rest/services/Services_Public_GISviewer/Parks_Recreation/MapServer) says `Copyright Text: Norfolk GIS`. Norfolk County's [Open Data Portal](https://opendata.norfolkcounty.ca/) links an [Open Data Licence](https://data-norfolk.opendata.arcgis.com/pages/terms-of-use) that permits copying, publishing, adapting, and commercial use of information made available under that licence. Its conditions include avoiding any suggestion of county endorsement and avoiding misrepresentation; county credit is optional. The portal's [Parks dataset](https://opendata.norfolkcounty.ca/datasets/21e6c39122fc4f18bcfb4333c4618858_0/explore) displays a custom licence and has 78 records, but it is a different hosted service from the 97-record `MapServer/6` layer used here. Searches of the portal on November 10, 2026 returned no woodlot or tree inventory datasets. The portal licence therefore **has not been verified for the exact three live REST layers in this app**. Public access and CORS are not a reuse licence. This app uses direct live links, attributes Norfolk GIS, and does not redistribute a bulk copy. Ask Norfolk GIS whether these exact three service layers may be displayed in an independent public portfolio app before wider promotion or adding downloadable data.

Esri's [licensing and attribution guidance](https://location.arcgis.com/help/licensing-and-attribution/) requires attribution for Esri basemaps and services. The app retains SDK attribution and gives Norfolk GIS source credit. The production map uses Esri's tile-based basemap usage model: opening, panning, or zooming can consume tiles. Esri currently includes [2 million free basemap tiles per month](https://developers.arcgis.com/rest/basemap-styles/). The Norfolk layers are fetched from Norfolk's own server, outside this ArcGIS Location Platform basemap allowance. For no-payment-method operation, see Esri's [billing guidance](https://location.arcgis.com/help/billing/): with pay-as-you-go disabled, the basemap service loses access after its free tier is exhausted until the next billing cycle. This is an access limit, not a guarantee of uninterrupted service.
